Tujuan Pembelajaran

Setelah menyelesaikan Lab Coding Blok, kamu diharapkan mampu:

  1. Memahami konsep algoritma — menjelaskan bahwa komputer bekerja mengikuti urutan instruksi yang tepat dan berurutan.
  2. Menerapkan tiga struktur logika — menggunakan urutan (sequence), pengulangan (loop), dan percabangan (if-else) untuk menyelesaikan masalah sederhana.
  3. Mengembangkan kemampuan debug — menemukan kesalahan dalam program blok dan memperbaikinya secara mandiri.
  4. Menghubungkan coding dengan kehidupan — mencontohkan penerapan logika pemrograman pada teknologi yang kamu gunakan sehari-hari.
Kurikulum Merdeka — Keterampilan Koding & Kecerdasan Artifisial, Paket B (Fase D).
